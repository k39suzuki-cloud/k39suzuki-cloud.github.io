Nil / Sol 幾何ウォークスルー

Thurston の 8 幾何のうち可解 Lie 群型の 2 つ — 左不変計量とその商多様体
Nil : ds² = dx² + dy² + (dz − x dy)²
Sol : ds² = e^{2z} dx² + e^{−2z} dy² + dz²

各ピクセルの視線方向について測地線の常微分方程式を RK4 で数値積分し、 「光が実際に曲がって進む」様子をそのまま描画しています（Riemannian ray marching）。

Nil は Heisenberg nilmanifold（格子 Γ = ℤ³ の商）。格子球とロッドが空間を敷き詰めます。

Sol は Anosov 行列 A = [[2,1],[1,1]] をモノドロミーとする トーラス束 M = Sol/Γ。ℤ² ファイバーを可視化しており、 鉛直方向に進むと上下のトーラス格子が A で次々にシアされていくのが見えます。 z 方向の周期は 1 ではなく log λ（λ = (3+√5)/2）であることが本質です。
